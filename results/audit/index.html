              Aspect Paper Ours Match

              Read these before trusting a comparison

              • Hardware differs. MuJoCo Warp runs about as fast on the A6000 as the paper reports for the H100, while SuperMimic's MLP-heavy updates run several times slower, so wall-clock comparisons here favor PPO-Sim.
              • Training time excludes benchmark evaluation, as in the paper, and includes the one-time torch.compile warm-up at the start of each run.
              • The PPO-Sim run started before the training-return definition was fixed, so only its benchmark evaluations are shown.
              • The headline result on the full BONES-SEED benchmark against SONIC cannot be run until the dataset's license is accepted on HuggingFace.

              Check it yourself

              From the project directory on the cluster. The status script prints every run's latest training and benchmark numbers; the export script rebuilds this page's data from the same logs.

              cd /n/fs/pci-sharedt/junqiyou/supermimic_repro
python3 code/scripts/status.py               # latest numbers per run
python3 code/scripts/export_audit.py         # rebuild this page's data
less notes/IMPLEMENTATION.md notes/RESULTS.md
ls paper/src/sections                        # the paper's TeX, source of every "paper" figure
# re-score a checkpoint on the benchmark (inside a GPU job):
source env.sh; source setup_local_env.sh
$SMIMIC_PY -m supermimic.evaluate --run runs/smimic_lafan1_1gpu --out eval_recheck.jsonl
